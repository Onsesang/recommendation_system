# 시각장애인을 위한 리뷰 기반 의류 촉감 검색·추천 파이프라인

> Amazon Fashion 리뷰에서 소재·촉감 근거를 수집하고, 이를 상품 검색·비교·추천에 활용하는 프로젝트

---

## 1. 프로젝트 목표

온라인 쇼핑에서는 상품 이미지와 일반 설명만으로 부드러움, 까끌함, 두께, 비침, 신축성, 보온성, 세탁 후 변형과 같은 정보를 파악하기 어렵다. 특히 시각장애인은 이미지 중심의 상품 탐색에서 더 큰 정보 격차를 경험할 수 있다.

본 프로젝트는 실제 구매자 리뷰에 포함된 소재·촉감 표현을 수집해 상품별 촉감 표현을 만들고, 다음 기능에 활용하는 것을 목표로 한다.

- 자연어·음성 기반 촉감 검색
- 현재 상품과 촉감이 비슷한 상품 추천
- 더 부드럽거나 덜 얇은 상품과 같은 방향성 대안 추천
- 여러 상품의 촉감 비교
- 실제 구매자 리뷰에 근거한 설명 제공

---

## 2. 전체 파이프라인

```text
[Amazon Fashion 데이터]
리뷰 · 별점 · 사용자 · 시간 · 상품 이미지
                │
                ▼
[1. 리뷰 데이터 구성]
Train split에서 이미지와 다수 사용자 리뷰가 있는 상품 선정
500상품 · 4,158리뷰
                │
                ▼
[2. 촉감 근거 추출]
Qwen이 리뷰에서 소재·촉감 표현을 원문 그대로 추출
                │
                ▼
[3. 의미 검증 및 구조화]
실제 촉감 근거인지 판정하고 속성·부위·극성·강도 구조화
                │
                ▼
[4. 상품 촉감 벡터 생성]
Claim을 BGE로 임베딩
Claim → 사용자 → 상품 순서로 집계
                │
                ▼
[5. 이미지 기반 Cold-start]
FashionCLIP 이미지 특징 + 카테고리
→ Ridge → 리뷰 촉감 공간의 벡터 예측
                │
                ▼
[6. 리뷰·이미지 Hybrid 상품 표현]
리뷰 근거와 이미지 예측을 근거량에 따라 결합
                │
                ▼
[7. 검색·추천]
자연어 검색 · 촉감 유사상품 · 방향성 대안 · 상품 비교
                │
                ▼
[8. 근거 기반 설명]
추천 이유와 실제 구매자 리뷰 문장을 함께 제공
```

---

## 3. 단계별 핵심 설명

### 1) 리뷰 데이터 구성

Amazon Fashion의 공식 train split만 사용했다. 이미지가 존재하고 서로 다른 사용자의 리뷰가 최소 5개 이상 있는 상품 중 500개를 선정했으며, 사용자당 리뷰 하나만 사용해 특정 사용자가 상품 표현을 과도하게 지배하지 않도록 했다.

| 항목 | 데이터 |
|---|---:|
| 상품 | 500개 |
| 리뷰 | 4,158개 |
| 상품당 리뷰 | 5~10개 |
| 이미지 | 모든 상품에 존재 |

### 2) 리뷰에서 촉감 근거 추출

Qwen이 리뷰를 요약하지 않고 소재·촉감과 관련된 표현을 원문 그대로 추출한다.

```text
Review
"The fabric is soft and warm, but it became loose after washing."

Extracted evidence
"soft and warm"
"became loose after washing"
```

누락을 줄이기 위해 두 관점으로 리뷰를 읽는다.

- 표면·착용: 부드러움, 까끌함, 두께, 비침, 신축성, 통기성, 보온성 등
- 세탁·행동: 수축, 보풀, 늘어남, 형태 변화, 내구성, 안감·마감 등

추출 문장이 실제 리뷰 원문에 존재하는지는 별도로 검사한다. 원문을 바꿔 쓰거나 추측한 문장은 근거로 사용하지 않는다.

### 3) 의미 검증 및 구조화

이 단계도 Qwen이 수행한다. 1차 추출과는 별도의 2차 의미 검증 단계로, Qwen에 추출된 exact span과 리뷰 전체 문맥을 함께 입력한다. Qwen은 해당 문장이 실제 소재·촉감 근거인지 다시 판정하고 다음 정보를 구조화한다.

- 촉감에 관한 짧은 claim
- 해당 부위 또는 범위
- 속성의 존재·부재·비교 여부
- 긍정·부정과 강도
- 직접 촉감, 착용 경험, 세탁 후 변화 등의 근거 유형
- 이미지에서 관찰 가능한 정도

현재 4,158개 리뷰에서 exact span 6,345개를 추출했고, Qwen 의미 검증기가 이 가운데 4,527개 claim을 채택했다. 이 4,527개는 Qwen이 생성한 pseudo-label이며, 독립적인 사람 검증 완료 데이터는 아니다.

### 4) 상품별 촉감 벡터 생성

채택된 자유 텍스트 claim을 BGE 문장 임베딩 모델로 변환해 384차원 벡터로 만든다.

```text
Claim 벡터
→ 같은 사용자 안의 중복 표현 제거
→ 사용자별 평균
→ 상품 안에서 사용자별 동일 가중 평균
→ 상품 촉감 벡터
```

이를 통해 리뷰를 많이 작성한 한 사용자가 상품 전체 표현을 과도하게 지배하지 않도록 한다.

현재 500개 상품 중 495개에 촉감 벡터가 생성됐으며, 이 가운데 470개 상품은 서로 다른 사용자 2명 이상의 촉감 근거를 가진다.

### 5) 이미지 기반 Cold-start

신규 상품처럼 리뷰가 없거나 부족한 경우에는 상품 이미지로 리뷰 촉감 공간의 벡터를 예측한다.

```text
FashionCLIP 이미지 벡터 512차원
+ 상품 카테고리
→ Ridge 회귀 모델
→ 리뷰 촉감 공간의 384차원 예측 벡터
```

따라서 이미지는 사용자가 반드시 검색 입력으로 제공해야 하는 것이 아니다. 리뷰가 부족한 상품에도 내부적으로 촉감 표현을 부여하기 위한 수단이다.

### 6) 리뷰·이미지 Hybrid 표현

최종 검색용 상품 표현은 리뷰 근거와 이미지 예측을 결합한다.

- 리뷰가 충분한 상품: 리뷰 벡터 비중 증가
- 리뷰가 부족한 상품: 이미지 예측 비중 증가
- 리뷰가 없는 상품: 이미지 예측만 사용하고 `이미지 기반 예상`으로 표시

이미지 예측은 추천 순위에는 사용할 수 있지만, 실제 구매자가 말한 촉감 설명처럼 제시하지 않는다.

중복 상품을 묶은 최종 465개 상품군 가운데 461개는 리뷰와 이미지를 결합하고, 4개는 이미지 예측만 사용한다.

### 7) 사용자 검색·추천

현재 주요 사용자 흐름은 이미지 검색이 아니라 자연어 또는 현재 보고 있는 상품을 이용한 탐색이다.

```text
"세탁 후 잘 늘어나지 않는 치마를 찾아줘."
        │
        ▼
카테고리: 치마
원하는 방향: 신축성이 더 적음
        │
        ▼
후보 상품 선택 → 촉감 조건으로 순위화 → 리뷰 근거와 함께 제시
```

현재 프로토타입은 사용자 요청 시 Qwen을 실행하지 않고, 한국어·영어 표현을 규칙 기반으로 구조화한다. 복합적인 자연어 조건은 향후 structured-output LLM을 결합해 확장할 수 있다.

상품 상세에서는 다음 결과를 구분해 제공한다.

- **디자인 유사상품**: FashionCLIP 이미지 유사도 중심
- **촉감 유사상품**: 리뷰·이미지 Hybrid 촉감 벡터 유사도 중심
- **방향성 대안**: 현재 상품보다 더 부드럽거나 덜 얇은 상품

### 8) 근거 기반 설명

추천 결과에는 가능한 경우 실제 리뷰 문장을 함께 제공한다.

```text
추천 이유
"현재 상품보다 부드러움에 관한 근거가 많은 상품입니다."

실제 구매자 리뷰
"The material is very soft against the skin."
```

시스템이 정리한 설명과 실제 리뷰 인용문을 구분하며, 근거가 부족하면 내용을 추측하지 않고 `근거 부족` 상태를 반환한다.

## 4. 평가 방법

Amazon 데이터에는 리뷰, 별점, 사용자 행동과 시간은 있지만 **상품 촉감에 대한 정답 label은 없다**. 따라서 평가 목적에 따라 서로 다른 ground truth 또는 proxy를 사용한다.

### 리뷰 추출 평가

- 추출 문장이 리뷰 원문에 정확히 존재하는지 자동 검사
- 실제 촉감 표현인지, 놓친 표현이 있는지는 사람 검수로 precision·recall 평가

현재 최신 결과는 Qwen pseudo-label과 개발용 AI 검수의 영향을 받았으므로, 독립적인 human gold 평가는 추가로 필요하다.

### 이미지→촉감 Cold-start 평가

이미지로 예측한 벡터를 해당 상품의 실제 리뷰에서 만든 촉감 벡터와 비교한다. 상품군 단위로 Train 321개, Development 70개, Locked test 70개로 분리했으며, Ridge가 현재 비교 방법 중 가장 높은 결과를 보였다.

| 방법 | Centered cosine | Same-category Recall@5 | NDCG@5 |
|---|---:|---:|---:|
| 카테고리 평균 | 0.0998 | 0.1400 | 0.7367 |
| FashionCLIP 이미지 | - | 0.2171 | 0.7762 |
| MLP | 0.1323 | 0.2371 | 0.7990 |
| **Ridge** | **0.2006** | **0.2657** | **0.8093** |

다만 이는 사람이 직접 부여한 촉감 정답이 아니라 리뷰 기반 상품 벡터를 proxy ground truth로 사용한 결과다.

### 다음 상품 추천 평가

사용자의 별점 4~5 상품을 시간순으로 정렬하고, 과거 상품을 학습 이력으로 사용해 마지막 상품을 맞히는 방식으로 평가한다.

현재 촉감 정보를 추가해도 Recall과 nDCG 개선은 관찰되지 않았다. 332개 평가 case 중 test 정답에 촉감 벡터가 있는 경우가 5개뿐이고, 후보 상품의 촉감 coverage도 3.25%로 매우 낮기 때문이다.

따라서 현재 결과는 다음과 같이 해석한다.

> 촉감 정보가 추천에 효과가 없다고 결론 내릴 수 있는 것이 아니라, 현재 데이터 coverage로는 효과를 판단할 수 없다.

## 5. 현재 결론과 남은 검증

### 현재 확인된 결과

- 실제 리뷰 문장을 보존하는 촉감 근거 추출 파이프라인을 구축했다.
- 4,158개 리뷰에서 4,527개 촉감 claim을 구성했다.
- 500개 상품 중 495개에 리뷰 기반 촉감 벡터를 만들었다.
- 자연어 검색, 촉감 유사상품, 방향성 대안, 상품 비교와 리뷰 근거 설명을 연결했다.
- 이미지로 리뷰 촉감 공간을 예측하는 Ridge가 현재 cold-start proxy 평가에서 비교 방법보다 높은 결과를 보였다.

### 추가 검증이 필요한 부분

- 최신 촉감 claim의 독립적인 사람 기준 정확도
- 이미지 예측과 사람이 판단한 실제 촉감의 일치도
- 충분한 coverage에서 촉감 정보가 추천 정확도를 개선하는지 여부
- 추천과 설명이 시각장애인의 실제 쇼핑 의사결정에 도움이 되는지 여부
