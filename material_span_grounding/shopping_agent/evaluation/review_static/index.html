추천 검수 기준

사용자 요청과 비교해 이미지와 상품명으로 판단합니다. 촉감 수치는 이미지로 예측한 참고값이라 판정 근거로 쓰지 않아도 됩니다.

맞음요청한 옷 종류이고, 요청한 조건(촉감·색·계절 등)과 어긋나지 않는다. 사용자에게 그대로 보여줘도 괜찮다.
예: "따뜻한 코트" → 두툼한 울 코트
애매옷 종류는 비슷하지만 조건 일부가 약하거나 확인할 수 없다. 보여줘도 되지만 1순위로는 아쉽다.
예: "바지" → 레깅스, "겨울 코트" → 얇은 트렌치코트, 성인 요청에 아동복인지 불분명
안 맞음옷 종류가 다르거나, 요청과 반대 조건이거나, 명백히 엉뚱하다.
예: "원피스" → 수영복, "안 비치는 티셔츠" → 망사 티셔츠, "시원한 셔츠" → 기모 셔츠

같은 턴에서 여러 설정이 추천한 상품은 한 번만 판정합니다. 상품 카드의 "순위" 표시는 어떤 설정이 몇 번째로 추천했는지입니다. 이미지를 누르면 크게 볼 수 있습니다.

대화 검수 기준

조건 해석검색 도구의 옷 종류·want·avoid가 요청 의미와 맞는가. 말하지 않은 촉감을 추측해 넣거나 반대로 해석하면 X. 검색이 없는 턴은 해당 없음.
지칭"2번", "그거", "방금 담은 거"가 화면 목록 번호 기준으로 맞는 상품을 가리키는가. 모호할 때 되묻거나 없는 번호를 거절하면 O.
근거 정직성가격·사이즈·재고·리뷰를 지어내지 않는가. 이미지 예측을 리뷰처럼 말하거나, 하지 않은 일·할 수 없는 일을 말하면 X.

판정은 누를 때마다 바로 저장됩니다. 키보드 ← → 로 페이지를 넘길 수 있습니다(메모 입력 중 제외).
